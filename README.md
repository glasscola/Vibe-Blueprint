# Vibe Blueprint

Turn your ideas into clear, actionable AI coding prompts.

프로젝트의 목적, 사용자와 기기, 기능, 디자인을 정리하고 AI에 붙여넣을 프롬프트를 만듭니다. 프로젝트 유형 버튼은 관련 기능을 자동으로 체크합니다. 작성한 초안은 현재 브라우저에 저장됩니다.

`index.html`을 브라우저에서 열거나, 이 폴더에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`에 접속하세요. 별도 빌드나 API 키가 필요 없습니다.
