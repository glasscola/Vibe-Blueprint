# Vibe Blueprint

Turn your ideas into clear, actionable AI coding prompts.

프로젝트의 목적, 사용자와 기기, 기능, 디자인을 정리하고 AI에 붙여넣을 프롬프트를 만듭니다. 프로젝트 유형 버튼은 관련 기능을 자동으로 체크합니다. 작성한 초안은 현재 브라우저에 저장됩니다.

화면·디자인에서는 편안한 구조, 깔끔한 구조, 생동감 있는 구조, 정보 중심 구조와 모바일·쇼핑몰·포트폴리오·게임용 추천 조합을 제공합니다. 조합을 누르면 스타일, 베이스 색, 포인트 색, 여백·글자·모서리 설정과 화면 요소가 함께 선택됩니다. 다른 조합을 적용하면 디자인 선택이 교체되며, 기능 선택과 직접 작성한 요청은 유지됩니다. 적용 직후 되돌리거나 각 항목을 개별 수정할 수 있습니다.

6가지 디자인 스타일과 25가지 화면 요소에 구체적인 설명을 제공하며, 최종 프롬프트에는 배치·색 사용·크기 기준·모바일 대응 지침까지 포함됩니다. 기존에 저장한 초안도 이어서 사용할 수 있습니다.

`index.html`을 브라우저에서 열거나, 이 폴더에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`에 접속하세요. 별도 빌드나 API 키가 필요 없습니다.
